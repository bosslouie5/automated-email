# AutoMail — Email Automation Mockup

This workspace contains a design-first frontend mockup for an Outlook email automation app.

Files:
- `index.html` — high-fidelity mockup and composer UI
- `styles.css` — design system and animations
- `script.js` — small interactions (attachments, preview, simulated send)

Open `index.html` in a browser to view the mockup.
